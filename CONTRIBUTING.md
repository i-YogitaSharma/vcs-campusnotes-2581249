
# Contributing to CampusNotes

## Project Overview
CampusNotes is a student-focused project for organizing academic notes.

## How to Contribute
1. Fork the repository.
2. Clone your fork.
3. Create a feature branch.
4. Make meaningful changes.
5. Commit your changes.
6. Push your branch.
7. Open a Pull Request.

## Branch Naming Convention
- feature/your-name-change
- fix/issue-description
- docs/documentation-update

## Commit Message Convention
- feat: Add a new feature
- fix: Fix an existing issue
- docs: Update documentation
- refactor: Improve existing code
- chore: Perform maintenance

## Pull Request Guidelines
- Use a descriptive title.
- Explain what changes were made.
- Explain why the changes are needed.
- Link the related issue.
- Request a review before merging.

## Code of Conduct
Be respectful and maintain clear communication
while collaborating with other contributors.
